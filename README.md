# Тренажёр русского жестового языка

Выполнен **этап 1 из 12 — основа приложения**. На `/` открыт временный проверочный экран, а не готовый landing или учебный сценарий.

## Запуск

Требуется Node.js 22.12+.

Все команды выполняются из каталога `CCURT`. Если терминал открыт в родительском `AdmitHack`, сначала выполните `cd CCURT`.

```sh
npm ci
npm run dev
```

Открыть <http://127.0.0.1:5173>.

```sh
npm run lint
npm run typecheck
npm run build
npm run preview
```

Последняя команда открывает production-сборку на <http://127.0.0.1:4173>.

## Что готово

- Vite, React 18, строгий TypeScript, Tailwind CSS, React Router, Lucide React и Framer Motion.
- Токены цветов, радиусов, теней и длительности переходов; локальный Manrope с кириллицей.
- Базовые `Button`, `Card`, `Logo`, `ErrorBoundary`, компонент эталонного материала с честной заглушкой.
- Маршруты `/` и `*` (404); остальные адреса определены константами, но страницы ещё не подключены.
- 20 уроков в двух разделах. Первые пять уроков алфавита — новый материал, следующие пять — повторение.
- Асинхронный `LessonRepository`: страницы получают доменные модели через сервис.
- Типы пользователя, настроек, учебной сессии, прогресса и результата распознавания.
- Контракт `VisionAdapter` с отдельной доставкой семантических результатов и кадровых данных.
- Поддержка reduced motion, видимый keyboard focus, ссылка перехода к основному содержимому.
- SPA rewrite для Vercel в `vercel.json`.

## Структура

```text
src/
  app/                  # App, router, название и адреса
  components/common/    # Базовые UI-компоненты
  components/lessons/   # Эталон/заглушка учебного материала
  data/                 # 20 записей уроков
  lib/                  # Небольшие общие функции
  pages/                # Временный экран основы и 404
  services/             # Репозиторий учебного контента
  types/                # Доменная модель и граница CV/UI
  styles.css            # Токены, Tailwind, адаптивные стили
public/assets/
  branding/
  gestures/
  sounds/
```

Название продукта меняется в одном месте: `src/app/constants.ts`, `APP_NAME`.
Приложение расположено в `CCURT/`; существующие Git-метаданные этого каталога сохранены.

## Проверка этапа 1

1. Открыть `/`: должны появиться логотип, описание основы и карточка «Первые буквы».
2. Нажать «Посмотреть основные слова»: карточка меняется на «Приветствие». «Вернуть алфавит» возвращает первую карточку.
3. Открыть неизвестный адрес, например `/missing`: проверить страницу 404 и кнопку «На главную».
4. Проверить ширины 1440, 1024 и 390 px; на телефоне блоки перестраиваются в одну колонку.
5. Проверить Tab/Enter и системное уменьшение движения.
6. Запустить `npm run build` и `npm run lint`.

Проверено при завершении этапа: build и lint проходят; 20 уроков имеют уникальные ID и корректную последовательность. В изолированном Chrome проверены dev- и production-сборки на 1440/1024/390 px: переключение разделов, 404 с обновлением страницы, возврат домой и клавиатурная навигация работают; горизонтального переполнения и ошибок JavaScript нет. Скриншоты просмотрены, автоматическая проверка axe по WCAG A/AA не выявила нарушений. Это не заменяет полноценный аудит доступности. Safari/Edge и реальное развёртывание Vercel на этом этапе не проверялись.

## Границы текущего этапа

Контент уроков — демонстрационные записи. Проверенных изображений, GIF и видео РЖЯ нет; приложение не изображает выдуманные положения рук. Тип движения у слов — предварительная метаинформация, которую необходимо проверить вместе с эталонными материалами.

Гостевой вход, регистрация, калибровка, личный кабинет, прохождение урока, `MockVisionAdapter`, canvas-рендерер и сохранение прогресса **пока не реализованы**. Камера не запрашивается, распознавание не запускается. Карточки состояний на проверочном экране — примеры оформления, а не результат анализа руки.

Следующий шаг — этап 2: landing, mock auth, гостевой вход и подтверждение email. Страницы приложения будут подключаться по мере реализации; guard для гостя/аккаунта появится вместе с AuthContext. Разделы `context`, `hooks` и `integrations` будут добавлены, когда появятся реальные реализации, а не пустые заглушки.

## Граница распознавания

Будущий адаптер получает видео и выполняет распознавание вне React. `subscribe` доставляет итоговые состояния с частотой не более 5–10 Гц. `subscribeFrames` предназначен для refs/canvas; координаты руки нельзя хранить в React state. MediaPipe, нормализация, сопоставление и анализ ошибок не входят в UI-компоненты.

## Развёртывание

Для Vercel: команда сборки `npm run build`, каталог результата `dist`. `vercel.json` возвращает `index.html` для SPA-адресов. В production камера на следующих этапах потребует HTTPS; localhost подходит для разработки.

Конфигурация опирается на официальные инструкции [Vite](https://vite.dev/guide/) и [Tailwind для Vite](https://tailwindcss.com/docs/installation/using-vite).
