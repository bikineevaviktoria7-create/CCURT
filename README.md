# SignStep

**Жесты, которые становятся понятными: изучайте русский жестовый язык, практикуйтесь перед камерой и получайте конкретные подсказки.**

## Идея продукта

По картинке или видео можно запомнить жест, но трудно понять, насколько точно повторяешь его сам. Какой палец согнуть? Куда повернуть ладонь? Что исправить в движении?

SignStep соединяет учебный материал с практикой и обратной связью. Пользователь изучает жест, показывает его в камеру и получает понятное действие для исправления ошибки. Короткие уроки, звёзды и видимый прогресс помогают возвращаться к занятиям и замечать собственный результат.

### Как проходит обучение

```text
Старт → Вход → Дорожка уроков → Страница занятия
                                      ↓
                             Изучение всех жестов
                                      ↓
                            «Теперь попробуйте сами»
                                      ↓
                   Практика → Подсказка → Исправление → Успех
                                      ↓
                          Итоги → Следующий урок / Главная
```

1. **Выберите урок.** На дорожке видны завершённые занятия, текущий шаг и доступные уроки
2. **Изучите все жесты.** Сначала иллюстрации и описания всего урока, затем практика в том же порядке
3. **Повторите перед камерой.** Следите за подсказкой, подсветкой руки и кольцом удержания
4. **Подготовьтесь к следующему жесту.** После успеха появляется короткий отсчёт. Смена положения руки в этот момент не добавляет ошибок
5. **Посмотрите результат.** Точность, очки, звёзды и частые ошибки показывают, что получилось и к чему стоит вернуться

Без входа доступен **предпросмотр**: упражнение на обнаружение и удержание руки в кадре. Это знакомство с камерой и обратной связью; полный курс открывается после входа в демо-аккаунт.

### Главная особенность

**Подсказка отвечает на вопрос «что исправить?»**

Примеры сообщений из приложения:

> Согните мизинец – сейчас он выпрямлен

> Соедините большой и указательный пальцы – кончики должны касаться

Вместе с текстом приложение выделяет соответствующие участки на скелете руки. Для движений предусмотрены подсказки по положению руки, амплитуде и скорости. Если рука выходит из кадра, сначала появляется помощь с её видимостью.

Успех сопровождается визуальным подтверждением. Следующий жест включается автоматически, а неполучившийся можно пропустить и повторить при новом прохождении урока.

### Возможности

- **26 уроков на одной дорожке:** 16 занятий по алфавиту, включая повторение, и 10 по основным словам
- **Все 33 буквы** с иллюстрациями и описаниями; урок знакомства с возможностью показать собственное имя дактилем
- **Практика с камерой:** скелет руки, конкретные исправления и проверка устойчивого выполнения
- **Прогресс:** до 1000 очков за урок, 1–3 звезды, лучшие результаты, серия дней занятий и графики последних попыток
- **Обучение в своём темпе:** повтор урока, выбор ведущей руки, отключаемые звуки и озвучка
- **Адаптивный интерфейс:** визуальная обратная связь, управление с клавиатуры и поддержка уменьшения анимации

### Как работает распознавание

```text
Камера браузера
  ↓
MediaPipe → 21 точка руки; ориентиры тела для движений
  ↓
Нормализация положения, размера и ведущей руки
  ↓
Признаки: сгибание пальцев, расстояния, направление ладони
  ↓
Сравнение с образцами целевого жеста
  ↓
Анализ отклонений + стабилизация результата
  ↓
Текстовая подсказка, подсветка скелета, подтверждение успеха
```

**MediaPipe находит точки. Решение о жесте принимает код проекта.**

- [`normalizeHand()`](src/vision/normalize.ts) переносит начало координат в запястье, приводит размер ладони к общему масштабу и зеркалит левую руку. Значимый для жеста поворот сохраняется
- [`extractHandFeatures()`](src/vision/features.ts) вычисляет углы суставов, расстояния между пальцами и ориентацию ладони
- [`compareStaticGesture()`](src/vision/staticMatcher.ts) сравнивает признаки с образцами. Допустимое отклонение учитывает разброс записей; проверяется и сходство с другими жестами
- [`dynamicMatcher.ts`](src/vision/dynamicMatcher.ts) сравнивает последовательности движений методом DTW и анализирует положение, амплитуду и скорость
- [`analyzeGestureErrors()`](src/vision/errorAnalyzer.ts) находит значимые отклонения по группам признаков и связывает исправление с точками для подсветки
- [`stabilizer.ts`](src/vision/stabilizer.ts) проверяет удержание статического жеста и сглаживает смену подсказок

Распознавание отделено от React-компонентов. [Адаптер](src/integrations/mediaPipeVisionAdapter.ts) передаёт точки напрямую в Canvas, а состояние интерфейса обновляет примерно до 10 раз в секунду, с немедленной передачей успеха. Камера и цикл обработки освобождаются при выходе из практики.

Между успешно выполненными жестами действует пауза около **2,9 секунды**: подтверждение успеха и отсчёт 3–2–1. В это время распознавание приостановлено, поздние результаты игнорируются; ошибки и уверенность предыдущего жеста сбрасываются перед новой попыткой.

Кадры камеры обрабатываются на устройстве: приложение не отправляет видео на сервер. Модели и WASM загружаются из `public/`; для моделей предусмотрен резервный источник Google.

### Данные и текущая комплектация

В репозитории есть **33 SVG-иллюстрации букв и 758 образцов для 33 букв**, включая последовательности движений. Образцы загружаются из Supabase, сохранённых локальных данных и резервного файла [`public/data/samples.json`](public/data/samples.json).

**Раздел слов уже включён в структуру курса, но образцы распознавания слов в поставку не входят.** Для их оценки нужно добавить соответствующие материалы. При отсутствии образцов приложение сообщает, что оценка недоступна. Лингвистическую корректность учебных материалов и качество распознавания следует проверять отдельно; числовые результаты урока не являются метрикой точности модели.

Текущая авторизация использует три локальных демо-аккаунта. Результаты сохраняются в localStorage отдельно для каждого пользователя и переживают перезагрузку страницы. Итоговая учебная оценка учитывает ошибки и пропуски; повторное прохождение сохраняет лучшие очки и звёзды.

Код интеграции с Supabase и SQL-миграции сохранены: загрузка материалов, таблица рекордов и синхронизация результатов. **Синхронизация прогресса демо-аккаунтов отключена**, а таблица рекордов появляется только при настроенном Supabase. Для локального запуска backend не требуется.

### Быстрый запуск

Нужен **Node.js 22.12+**. Выполните команды из каталога с `package.json` (`CCURT`):

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Для практики разрешите доступ к камере. При размещении приложения на сервере требуется HTTPS.

| Демо-пользователь | Пароль |
| --- | --- |
| Руслана | `1237890q` |
| Камилла | `1237890q` |
| Мария | `1237890q` |

`npm ci` автоматически копирует WASM MediaPipe в `public/mediapipe/`. Если файлов моделей нет, восстановите их командой `npm run models`.

При необходимости подключения существующих интеграций Supabase задайте в `.env.local` значения `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Это не заменяет локальную демо-авторизацию серверной.

### Проверки и сборка

```sh
npm run build   # TypeScript + production-сборка в dist/
npm run lint    # Проверка исходного кода
npm test        # Автоматические тесты из dop/tests/
npm run preview
```

Тесты покрывают распознавание на синтетических данных, подсказки, жизненный цикл адаптера, последовательность урока и паузу между жестами, авторизацию, сохранение прогресса и звук. Они дополняют проверку на реальной камере, а не заменяют её.

Для Vercel: корневой каталог `CCURT`, команда сборки `npm run build`, результат `dist`. SPA-переходы при прямом открытии адресов настроены в [`vercel.json`](vercel.json).

### Структура проекта

```text
src/
  app/             Маршруты, константы и запуск приложения
  pages/           Экраны и пользовательский сценарий

  hooks/           Урок, камера и получение результатов распознавания
  vision/          Нормализация, признаки, сравнение и анализ ошибок
  integrations/    Связь MediaPipe с распознавателем и интерфейсом
  services/        Авторизация, загрузка материалов и прогресс
  context/         Текущий пользователь и состояние приложения
  data/            Алфавит и состав уроков
  lib/             Хранилища, Canvas, звук и небольшие утилиты
  types/           Типы данных
public/            Иллюстрации, образцы, модели и WASM
supabase/          SQL-миграции и начальные данные
dop/              Тесты, фикстуры, скрипты и документация
```

Для знакомства с ключевыми функциями откройте [карту кода для защиты](dop/CODE_DEFENSE.md). Форматы учебных материалов описаны в [заметках об иллюстрациях и образцах](dop/GESTURE_MEDIA.md).
