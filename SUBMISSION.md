# Описание проекта для формы сдачи

**SignStep — тренажёр русского жестового языка (направление C, свободный вариант).**

Веб-приложение для глухих и слабослышащих людей и их близких. Пользователь открывает ссылку, встаёт перед камерой и учит дактильную азбуку и базовые слова РЖЯ. Приложение распознаёт жест прямо в браузере: MediaPipe находит точки руки, а собственный алгоритм команды сравнивает их с эталонами из базы данных Supabase. Урок — законченный сценарий: теория с рисунком и описанием → практика с камерой → итоги (точность, очки, звёзды, частые ошибки) → следующий урок на дорожке из 20 уроков. Есть урок «Своё имя», где пользователь показывает своё имя дактилем.

**Какие жесты распознаются:** статичные буквы дактиля (А, Б, В, Г, Е, И, Л, М, Н, О, П, С, Т, У, Ш и другие для имени) — по форме руки. Слова (привет, спасибо, да, нет, пока и др.) и буквы с движением — по траектории (DTW). Обратная связь: скелет руки, подсветка пальцев, сходство с эталоном, кольцо удержания, счётчик.

**Как реализован режим «ошибка»:** в уроке целевой жест известен, поэтому попытка сравнивается с ближайшим эталоном этого жеста по каждой группе признаков: каждый палец, большой палец, разведение, поворот ладони, а для слов ещё положение руки, амплитуда и скорость. Порог ошибки вычисляется из разброса эталонов. Самое уверенное отклонение становится конкретной подсказкой, а ошибочный палец подсвечивается красным. Примеры:

- «Согните безымянный палец — сейчас он выпрямлен.»
- «Соедините большой и указательный пальцы — кончики должны касаться.»
- «Поверните ладонь к камере — сейчас она повёрнута ребром.»
- «Сейчас это похоже на «Б». …» — если показан другой жест из базы.
- «Сделайте движение шире.» — для слов.

Подсказка стабилизируется и не мигает, а частые ошибки видны на экране итогов.

**Сверх минимума:**

- собственная логика распознавания (kNN с автопорогами, DTW, анализ ошибок, 15 юнит-тестов);
- регистрация с настоящим кодом на email;
- база эталонов и админ-панель, где эталон жеста записывается прямо с камеры (сохраняются только координаты пальцев, без фото);
- прогресс с синхронизацией между устройствами, диаграмма точности, серия дней, таблица рекордов;
- звуки, озвучка, вибрация;
- адаптивная вёрстка для телефона.

Видео не покидает устройство.
