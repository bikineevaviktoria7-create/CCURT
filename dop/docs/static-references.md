# Статические эталоны и диагностика

## Что проверяется

Один путь для всех заданий: HandLandmarker → normalizeHand → extractHandFeatures →
compareStaticGesture → HoldStabilizer → analyzeGestureErrors. Для жестов с движением
`positionOnly: true` показывает ограничение в теории и практике. Движение, направление,
скорость и расположение относительно тела не оцениваются.

## Покрытие данных

В поставке 732 вектора версии 1 длиной 34 для 24 букв. Отсутствуют статические
эталоны Д (`letter-16`), Ё (17), З (19), Й (20), К (21), Ц (25), Щ (27), Ъ (28), Ь (30).
Их 26 старых последовательностей содержат только 8 признаков на кадр, исходные
landmarks пусты. Перевести их в полноценные статические эталоны достоверно нельзя.
Файл данных сохранён, последовательности игнорируются.

У активных слов Привет (`word-hello`), Пока (`word-goodbye`), Да (`word-yes`),
Нет (`word-no`) нет ни статических образцов, ни проверенных учебных изображений/видео.
Повторение и итоговый урок используют те же IDs. Без образцов показывается
"Оценка недоступна", без confidence, hold и автоматических ошибок ученика.
Ручной пропуск сохраняет прежние правила баллов.

Не назначайте этим жестам произвольные позы и не копируйте похожую букву без проверки
специалистом. Иллюстрация или видео не заменяют числовой образец для распознавателя.

## Как подключить проверенный образец

Существующий `GestureSample`: `id`, правильный `gestureId`, `featureVersion: 1`,
`features` из `extractHandFeatures(worldLandmarks, фактическаяРука)` – 34 конечных числа.
Признаки уже нормализованы. Не зеркальте их повторно из-за зеркального video.
Храните исходные world landmarks и handedness для дальнейшей проверки происхождения.
Нужны несколько независимых записей выбранного ключевого положения; не добавляйте
весь путь руки как статические примеры. Используются прежние Supabase/local/bundle
источники, без отдельного API. Старые или неполные векторы отбрасываются **до** выбора
резервного источника, иначе они могли скрывать пригодный bundled-эталон.

Учебные материалы подключаются прежним `GestureContent.referenceMedia`: image/gif/video,
`src`, `alt`, опционально `poster`. В описании обозначьте, какое положение нужно удержать.

## Проверка базы

Проверены IDs всех 37 активных жестов (33 буквы и 4 слова), длины/версии векторов,
сравнение с остальными классами и удержание/сброс на синтетических landmarks.
Leave-one-out проверка исключает проверяемый образец из модели целевой буквы.
При существующем `bundle.tolerance = 1.55` отвергнуты 3 из 732 векторов:
два у И (выброс и более близкий образец Р), один у Н (выброс).
Все 192 образца Б, Г, Л, О, Т из итогового урока №10 прошли эту численную проверку.
Пороги, нормализация, признаки и стабилизатор не изменены.

Это **не** измерение точности на независимых людях: в комплекте нет исходных
landmarks этих записей. Для И/Н нужны дополнительные проверенные образцы; проблему
конкретного исполнения нужно воспроизвести на камере, а не исправлять ослаблением
глобального порога.

В dev-режиме `?visionDebug=1` показывает target/predicted, ближайший класс, расстояние,
порог, число пригодных образцов, confidence, hold и ошибки. Панель отсутствует в
production. Старые коды ошибок движений оставлены только для чтения сохранённых
результатов; активный распознаватель их больше не выдаёт.
