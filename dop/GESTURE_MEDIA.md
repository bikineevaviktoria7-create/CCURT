# Проверенные материалы РЖЯ

В репозитории есть иллюстрации алфавита и образцы в `public/data/samples.json`. Их лингвистическую корректность должна подтверждать команда со специалистом. MediaPipe обнаруживает точки руки; жест распознаёт собственный алгоритм по образцам.

## Как добавить

После проверки специалистом положите материалы в `public/assets/gestures/`, например letter-1.webp, word-hello.mp4. Добавьте соответствующий ID в src/data/alphabet.ts:

```ts
"letter-1": { kind: "image", src: "/assets/gestures/letter-1.webp", alt: "Проверенный эталон буквы А" }
// kind: image | gif | video; у video можно задать poster
```

Компонент GestureReference используется на странице занятия, в теории и практике. Он поддерживает отложенную загрузку, controls/playsInline для видео и placeholder при ошибке загрузки. Изображение не является CV-образцом: отдельно нужны проверенные features/sequence в samples.json.

## Что есть сейчас

- **33 буквы дактиля** — `letter-1.svg … letter-33.svg`, рисунки из таблицы дактильной азбуки (буква показана так, как её видит собеседник). Подключены в `src/data/alphabet.ts` и показываются в теории, на странице занятия, в карточке практики.
- **15 слов** — картинок пока нет, показывается заглушка. Сохранённое фото из репозитория используется для слов автоматически.

Рисунки — иллюстрации для ученика. Образцы распознавания хранят координаты руки отдельно, в `public/data/samples.json` и базе данных.
